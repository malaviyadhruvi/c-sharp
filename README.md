# Dry Fruits Management System

## 📌 About the Project

The **Dry Fruits Management System** is a management application developed using **C# and .NET** for managing the day-to-day operations of a dry fruits business.

The system is designed to manage products, companies, customers, purchases, sales, stock, sales returns, and reports.

The project is being developed step by step, and new features will be added and updated throughout the development process.

## 🛠️ Technologies Used

* **C#**
* **.NET**
* **Microsoft Access**
* **Visual Studio Express**
* **Git**
* **GitHub**

## 🗄️ Database

**Microsoft Access** is used as the database for storing and managing application data.

The database will contain information related to:

* User/Login
* Company
* Customer
* Product
* Purchase
* Sales
* Stock
* Sales Return
* Purchase Return

## ⚙️ Main Features

* Logout

* Add company

### 👥 Customer Management

* Add customer

### 📦 Product Management

* Add products
* Update products

* Record product purchases

* Stock

## 🎯 Project Objectives

* Reduce manual data management
* Maintain product and stock information efficiently
* Manage customer and company information

* Reduce data-entry errors
* Provide quick access to stored information
* Make searching and managing records easier
* Maintain business information in a centralized database
